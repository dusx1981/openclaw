# 电商图文创意生成 E-commerce AI Creative

基于AI自动生成商品文案和创意图片，帮助商家快速完成上新素材制作。

## 功能列表

| 功能       | 说明                 | 输出         |
| ---------- | -------------------- | ------------ |
| 标题生成   | 生成5种不同风格标题  | 5个标题      |
| 卖点提炼   | 生成5个短卖点文案    | 5个卖点      |
| 详情文案   | 生成详情页框架文案   | 完整详情文案 |
| 主图生成   | AI生成商品主图       | 图片文件     |
| 海报生成   | 生成活动海报         | 图片文件     |
| 问大家回复 | 生成用户问题自动回复 | 回复文案     |

## 工作流程

```
1. 获取商品信息
   • 从商品链接拉取基本信息
   • 或商家手动输入

2. 文案生成
   • 根据需求生成多版本文案
   • 不同风格满足不同场景

3. 图片生成 (可选)
   • 根据描述生成主图/海报
   • 提供多个版本

4. 交付商家
   • 列出所有版本供选择
   • 选中后可直接上传
```

## 完整工作流程

### 输入阶段

```
1. 获取商品信息
   A) 自动方式：提供商品ID → ecom-product-fetch拉取商品名称/分类/现有卖点
   B) 手动方式：商家直接输入：商品名、分类、核心卖点、价格
```

### 文案生成阶段

#### 1. 标题生成（5种风格）

| 风格           | 用途         | 特点           |
| -------------- | ------------ | -------------- |
| **搜索优化型** | 搜索算法推荐 | 塞满核心关键词 |
| **卖点突出型** | 吸引点击     | 开头放核心卖点 |
| **情感共鸣型** | 击中用户     | 直击痛点场景   |
| **活动营销型** | 活动期间     | 突出促销优惠   |
| **简洁干净型** | 现代风格     | 短小精悍       |

**Prompt模板：** 参见 [references/creative-prompts.md](./references/creative-prompts.md)

淘宝标题限制：\*\*30个汉字（60字符以内），生成时自动截断控制长度

#### 2. 卖点提炼

- 输出 \*\*N个卖点（默认5个）
- 每个卖点 **15个字以内**，适合主图卖点文字
- 要求：一个卖点一个核心优势，用数字增强说服力

#### 3. 详情页文案

生成固定结构框架：

1. **首屏痛点引入** - 抓住用户痛点引发共鸣
2. **产品介绍** - 我们的解决方案
3. **核心卖点展开** - 每个卖点一段话
4. **场景展示** - 适合人群/使用场景
5. **售后保障** - 打消购买顾虑

#### 4. 问大家回复

用户常见问题自动生成友好专业回复，控制在100字以内

---

### 图片生成阶段

#### 主图生成

```
商家输入：商品名称、核心卖点、风格
  ↓
用预定义模板拼接到image_generate提示词
  ↓
生成N张（默认2张不同版本
  ↓
交付商家选择
  ↓
选中后可通过taobao-shop-sync直接上传
```

\*\*三种风格模板：

- **极简风**：干净白色背景，产品居中，留白充足
- **营销风**：包含促销文字/价格标签，活泼色彩
- **高端风**：暗调轻奢，场景化背景，杂志质感

#### 活动海报生成

- 输入：活动名称（618/双11）、商品、优惠信息
- 输出：适合手机端展示的海报图片
- 要求：促销文字清晰可见，色彩吸引点击

## 数据流向

```
商家发起请求
   ↓
ecom-product-fetch (可选) → 获取现有商品信息
   ↓
LLM 生成文案（多版本
   ↓
image_generate (可选) → 生成图片
   ↓
整理结果展示给商家选择
   ↓
商家选中 → taobao-shop-sync → 直接上传到淘宝
```

## 配置参数

| 参数            | 默认值      | 说明                       |
| --------------- | ----------- | -------------------------- |
| `titleVersions` | 5           | 生成标题版本数             |
| `bulletCount`   | 5           | 卖点数量                   |
| `imageCount`    | 2           | 生成图片版本数             |
| `imageSize`     | `1024x1024` | 图片尺寸（淘宝主图正方形） |
| `aspectRatio`   | `1:1`       | 主图比例                   |

## 完整配置示例

```json
{
  "enabled": true,
  "defaults": {
    "titleVersions": 5,
    "bulletCount": 5,
    "imageCount": 2,
    "imageSize": "1024x1024",
    "defaultStyle": "minimal"
  },
  "taobao": {
    "autoUpload": false,
    "maxTitleLength": 30
  }
}
```

## 实现路径分步开发

### Phase 1：文案生成（1-2天）

1. ✅ **标题生成** - 五种风格prompt工程
2. ✅ **卖点提炼** - 短卖点输出
3. ✅ **详情文案框架** - 固定结构生成
4. 测试输出格式，控制长度符合平台限制

### Phase 2：图片生成（1天）

1. ✅ **主图生成** - 三种风格提示词模板
2. ✅ **活动海报** - 活动模板
3. 对接 `image_generate` 工具

### Phase 3：对接上传（1天）

1. ✅ 集成 `taobao-shop-sync`
2. 选中的文案/图片直接上传到淘宝商品
3. 测试端到端流程

### Phase 4：优化体验（持续

- 保存商家常用风格偏好
- 根据商家反馈调整prompt

## 依赖工具

- `ecom-product-fetch` - 拉取已有商品信息
- `image_generate` - AI生成图片（调用配置好的图像生成模型
- `taobao-shop-sync` - 上传商品到淘宝
- `message` - 通知商家生成完成
