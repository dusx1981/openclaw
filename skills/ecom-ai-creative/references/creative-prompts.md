# 创意生成提示词参考

## 1. 商品标题生成

### 系统提示词

```
你是一个资深淘宝电商文案师，请根据以下商品信息，生成5个不同风格的商品标题：
1. 搜索优化型 - 包含核心关键词，适合算法推荐
2. 卖点突出型 - 开头就放核心卖点吸引点击
3. 情感共鸣型 - 直击用户痛点/场景
4. 活动营销型 - 突出优惠活动促进点击
5. 简洁干净型 - 短小精悍，适合算法推荐

商品信息：
商品类别：{{category}}
商品名称：{{name}}
核心卖点：{{bullet_points}}
价格：{{price}}
活动：{{promotion}}

输出格式：
标题1（搜索优化型）：xxx
标题2（卖点突出型）：xxx
标题3（情感共鸣型）：xxx
标题4（活动营销型）：xxx
标题5（简洁干净型）：xxx
```

## 2. 商品卖点文案生成

```
请为这款{{category}}商品生成5个主图卖点文案，每个卖点控制在15字以内：

商品信息：
{{product_description}}

要求：
1. 每个卖点一句话，突出一个核心优势
2. 语言口语化，适合用户快速阅读
3. 尽量用数字增强说服力
```

## 3. 详情页文案生成

```
请为这款{{category}}商品生成详情页文案框架，包含以下模块：
1. 首屏痛点引入 - 抓住用户痛点引发共鸣
2. 产品介绍 - 我们的解决方案
3. 核心卖点3-5个 - 每个卖点配一句话说明
4. 场景展示 - 适合哪些人/哪些场景使用
5. 售后保障 - 打消购买顾虑

商品信息：
{{product_info}}

目标客群：{{target_audience}}
价格带：{{price_range}}
```

## 4. 主图生成提示词模板

\*\*基础模板：

```
电商商品主图，{{product_name}}，
核心卖点：{{key_bullet_point}},
风格：{{style}}，干净简约，突出产品，
高清产品摄影，专业布光，白色背景，淘宝主图尺寸，
8k，超清晰，商业摄影
```

**极简风**：`干净简约背景，产品居中，专业电商摄影，留白充足

**营销风**：`包含促销文字“限时优惠”，醒目的价格标签，活泼喜庆色彩

**高端风**：`暗调轻奢，质感高级，场景化背景，杂志封面风格
