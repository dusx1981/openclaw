# 广告投放智能优化 E-commerce Ad Optimization

基于每日投放数据，AI自动优化关键词出价和预算分配，提升整体ROI。

## 核心逻辑

```
每日优化循环：

1. 拉取数据 → 获取各计划/关键词的曝光、点击、转化、ROI
2. 数据分析 → 聚类高转化/低转化关键词
3. 预算调整 → 高ROI加预算，低ROI减预算或暂停
4. 关键词拓展 → AI挖掘新的长尾关键词机会
5. 生成日报 → 发送给商家确认
```

## 数据维度

需要从广告平台API获取以下指标：

| 指标                | 说明       |
| ------------------- | ---------- |
| `impressions`       | 曝光量     |
| `clicks`            | 点击量     |
| `spend`             | 花费       |
| `conversions`       | 转化数     |
| `gmv`               | 成交金额   |
| `roi` = gmv / spend | 投入产出比 |

## 优化规则

### 出价调整公式

```
如果 ROI > 目标ROI × 1.2:
    新出价 = 当前出价 × 1.10  (加10%)
如果 ROI < 目标ROI × 0.8:
    新出价 = 当前出价 × 0.90  (减10%)
如果 ROI < 目标ROI × 0.5 且 花费 > 限额:
    暂停该关键词
```

### 预算分配原则

- **80/20原则**：80%预算分配给TOP 20%高转化关键词
- **保留探索预算**：保留10%-15%预算给新关键词探索
- **每日调整限制**：单个关键词单日调整不超过20%，避免震荡

## 关键词拓展

### 挖掘新关键词流程

1. 分析当前高转化关键词特征
2. 使用电商搜索联想词/下拉推荐挖掘长尾词
3. AI过滤：去重、去低相关、预估转化潜力
4. 推荐20-50个新词给商家，商家确认后加入投放

## 完整实现机制

### 数据获取

```
每日定时优化触发
   ↓
1. 调用广告平台API获取数据
   • 每个关键词：曝光、点击、花费、转化、GMV
   ↓
2. 计算每个关键词ROI = GMV / 花费
   ↓
3. 和目标ROI对比 → 分类处理
```

### 出价调整规则

| ROI 区间                                  | 调整动作 | 调整幅度               |
| ----------------------------------------- | -------- | ---------------------- |
| ROI > 目标ROI × 1.2                       | 加价     | 当前出价 × 1.10 (+10%) |
| ROI < 目标ROI × 0.8                       | 降价     | 当前出价 × 0.90 (-10%) |
| ROI < 目标ROI × 0.5 **且** 花费已超日限额 | 暂停     | 直接暂停               |

**保护机制：**

- 单个关键词单日调整幅度不超过 `maxChangePercent` (默认20%)
- 避免价格震荡

### 预算分配策略

```
总预算
├─ 85% 分配给已验证高ROI关键词（80/20原则）
└─ 15% 预留作探索预算给新关键词
```

探索预算让系统持续发现新的优质关键词，避免流量枯竭。

## 关键词挖掘拓展

### 挖掘流程

```
1. 分析当前高ROI关键词 → 提取特征
   ↓
2. 挖掘长尾词来源：
   • 淘宝搜索下拉框联想词
   • 手机淘宝你是不是想找
   • 竞品标题关键词提取
   ↓
3. AI过滤：
   • 去重（已在投放中的词）
   • 去低相关（和产品不相关）
   • 预估竞争度
   ↓
4. 推荐 20-50 个新词给商家
   ↓
5. 商家确认后加入投放 → 占用探索预算
```

## 完整工作流时序

```
cron 每日定时触发（默认间隔 24 小时
   ↓
1. 拉取所有推广计划数据
   ↓
2. 遍历每个关键词：
   ↓
   a. 计算周期ROI
   ↓
   b. 根据规则判断调整方向
   ↓
   c. 检查单日幅度限制
   ↓
   d. 调用广告API执行调整
   ↓
3. 挖掘新关键词推荐
   ↓
4. 生成优化日报
   ↓
5. message发送给商家
```
