# 自动店铺巡检 Automatic Shop Inspection

每日定时巡检店铺，自动发现问题并通知商家，保证店铺正常运营。

## 巡检清单

默认每日检查项目：

- [ ] ✅ **价格检查** - 是否有商品价格异常（0元/天价）
- [ ] ✅ **库存检查** - 是否有热销商品库存过低缺货
- [ ] ✅ **素材合规检查** - 主图/详情页是否有违规词、违规内容
- [ ] ✅ **负面评价检查** - 是否新增大量差评/负面评价
- [ ] ✅ **竞品动态检查** - 主要竞品是否有上新/活动

## 工作流程

```
每日定时触发（cron）
    ↓
1. browser 打开店铺/商品页面
    ↓
2. 截图保存 + OCR识别文字
    ↓
3. AI检查：
   • 价格异常检测
   • 违规关键词匹配
   • 差评识别统计
    ↓
4. 汇总问题
    ↓
5. 如有问题 → 发送通知给商家
   无问题 → 静默完成
```

## 合规检查

### 违规关键词列表

常见违规词需要检测：

- 绝对化用词：最顶级、第一、最好、国家级...
- 医疗夸大：治病、防癌、减肥...
- 虚假承诺：100%有效、永不掉色...

商家可以自定义添加违规词列表。

## 实现细节

### 视觉检查流程

1. **截图**：`browser` 打开商品页，截取主图和详情区
2. **OCR**：`image` 技能识别图片中的文字
3. **匹配**：扫描文字中是否包含违规关键词
4. **告警**：发现违规词立即通知商家替换

### 差评检查

1. 拉取最新评价
2. AI识别差评（评分低 + 负面词汇）
3. 如果近7天差评率超过阈值 → 通知商家处理

## 配置

```json
{
  "schedule": "0 9 * * *", // 每天早上9点巡检
  "checks": {

    "inventory": true,
    "compliance": true,
    "negativeReview": true,
    "competitor": false

```

## 各检查项详细实现机制

### 1️⃣ 价格异常检查

\*\*实现流程：

```
1. taobao-shop-sync → 获取本店所有商品价格
2. 遍历检测异常：
   • 价格 = 0 → 异常
   • 价格 > 设定上限（如 10000元 → 异常
   • 价格 < 设定下限（如 1元 → 异常
3. 发现异常 → 立即通知商家
```

**异常原因：**

- 商家编辑商品时误输价格
- API同步错误
- 促销活动设置错误

---

### 2️⃣ 库存预警检查

**实现流程：**

```
1. taobao-shop-sync → 获取所有商品库存
2. 对每个商品：
   if 库存 < 配置阈值（默认10件
   → 加入预警列表
3. 汇总所有库存不足商品 → 通知商家补货
```

商家可按商品单独配置阈值：

- 热销商品阈值可设高一点（如30
- 滞销商品可设低一点（如5

---

### 3️⃣ 素材合规检查（广告法违禁词检测

**核心流程（图片素材需要OCR：**

```
1. 遍历商品主图和详情页图片
   ↓
2. browser → 打开商品页 → 截图
   ↓
3. image技能 → OCR识别图片中文字
   ↓
4. 扫描文字匹配违规词
   ↓
5. 发现违规词 → 记录商品 + 位置 + 违规词 → 通知商家
```

**默认违规词库：**

| 类别       | 违规词示例                               |
| ---------- | ---------------------------------------- |
| 绝对化用词 | 最、第一、最好、顶级、国家级、最高、冠军 |
| 医疗夸大   | 治病、防癌、减肥、抗癌、治疗             |
| 虚假承诺   | 100%有效、永不掉色、永不褪色、保证       |
| 权威背书   | 中南海、领导人、推荐                     |

商家可通过 `blockedWords` 配置添加自定义违规词。

---

### 4️⃣ 负面评价检查

**实现流程：**

```
1. 调用API拉取最近7天评价
   ↓
2. AI识别：
   • 评分 < 3星 → 标记差评
   • 评分≥3星但内容含负面词 → 标记差评
   ↓
3. 统计近24小时/近7天差评数量
   ↓
4. if 数量 ≥ 阈值（默认3个 → 通知商家处理
```

**负面词库：** 质量差、坏了、破了、假货、骗人、垃圾、褪色...

---

### 5️⃣ 竞品动态检查（可选

```
1. 遍历商家关注的竞品商品列表
   ↓
2. ecom-product-fetch → 获取竞品最新信息
   ↓
3. 检测变化：
   • 竞品降价
   • 竞品上新活动
   • 竞品新增评价
   ↓
4. 发现重大变化 → 通知商家
```

## 完整工作时序

```
cron 定时触发（默认每天早上9点
   ↓
1. 加载配置，获取需要检查的项目
   ↓
2. 依次执行各项检查：
   ↓
   • 价格检查 → API拉数据检测
   • 库存检查 → API拉数据检测
   • 合规检查 → browser截图 → OCR → 匹配违规词
   • 差评检查 → API拉评价 → AI识别统计
   • 竞品检查（可选 → 拉竞品数据检测
   ↓
3. 汇总所有问题
   ↓
4. if 有问题 → message发送巡检报告给商家
   if 无问题 → 静默结束，不打扰商家
```

## 分步实现路径

### Phase 1：数据检查（2天）

1. ✅ 价格异常检测
2. ✅ 库存预警
3. 对接 `taobao-shop-sync` 获取数据

### Phase 2：合规检查（2-3天）

1. ✅ browser截图商品页
2. ✅ image OCR文字识别
3. ✅ 违规词匹配算法
4. ✅ 发现违规通知

### Phase 3：评价检查（1-2天

1. ✅ 拉取评价API
2. ✅ AI差评识别
3. ✅ 统计超标通知

### Phase 4：竞品检查（可选，1天

1. ✅ 竞品监控列表
2. ✅ 变化检测通知

## 依赖工具

- `browser` - 打开店铺页面截图
- `image` - OCR文字识别（识别图片中违规词
- `taobao-shop-sync` - 获取商品价格库存数据
- `ecom-product-fetch` - 获取竞品信息
- `cron` - 每日定时触发
- `message` - 发现问题通知商家
