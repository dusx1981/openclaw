# 智能选品测款 E-commerce AI Product Selection

基于电商平台热销数据和AI分析，帮助商家发现潜力新品方向。

## 工作流程

```
1. 输入品类关键词 (如"夏季女装连衣裙")
2. 搜索电商平台获取热门商品数据
   ↓
3. AI分析维度：
   • 价格区间分布与竞争度
   • 销量排名与热门卖点
   • 市场空白与差异化机会
   • 利润空间测算
   ↓
4. 输出TOP N推荐列表
   • 每个推荐包含细分方向
   • 建议定价区间
   • 差异化卖点建议
   • 竞争度评估
```

## 使用示例

```
帮我在淘宝搜索"无线充电器"，推荐5个潜力新品方向
```

## 工具依赖

- `ecom-product-search` - 搜索电商平台商品
- `web_search` - 搜索行业趋势热词
- `sessions_spawn` - AI分析计算

## 配置参数

| 参数              | 说明           | 默认值   |

| `platform`        | 默认电商平台   | `taobao` |
| `resultCount`     | 输出推荐数量   | 5-10     |
| `minProfitMargin` | 最低利润率要求 | 0.3      |

## 算法逻辑

1. **价格分层**：将商品按价格分成低/中/高三档
2. **竞争度计算**：该价格带商品数量 ÷ 总销量
3. **机会识别**：寻找销量高但商家少的价格带/细分方向
4. **利润测算**：根据平台同类商品价格，预估毛利空间

## 详细算法逻辑

### 步骤1：数据采集

```
商家输入 → 核心关键词 (如"无线充电器")
   ↓
1. ecom-product-search → 搜索淘宝该关键词，获取TOP 50-100热销商品
   • 获取每个商品：标题、价格、销量、店铺
   ↓
2. web_search → 搜索行业热词、趋势资讯
   • 了解当下什么概念/功能热门
   ↓
3. 整合得到商品数据集
```

### 步骤2：价格分层与竞争度计算

**竞争度计算公式**：

```
竞争度 = (该价格带商品数量 ÷ 该价格带总销量)
```

- 竞争度越 **低** → 机会越大（销量很多但商家少）
- 竞争度越 **高** → 红海市场（商家多销量少）

**价格分层**：自动分成三档

```
低价位：< 50元
中价位：50 - 200元
高价位：> 200元
```

商家可自定义价格分层

### 步骤3：卖点词频统计

- 分词提取所有热销商品标题中的高频词
- 统计哪些卖点出现频率高
- 识别：
  • 热门卖点 → 消费者吃这一套
  • 冷门卖点 → 可能的差异化机会

### 步骤4：机会识别

优先推荐满足以下条件的细分方向：

```
✓ 竞争度 < 平均竞争度
✓ 满足最低利润率要求 (默认 >= 30%)
✓ 有差异化卖点可以挖掘
✓ 价格带市场需求足够（总销量不低）
```

### 步骤5：输出推荐报告

对每个推荐方向给出：

| 项目         | 内容                             |
| ------------ | -------------------------------- |
| 细分方向名称 | 如"迷你便携10000mAh自带线无线充" |
| 建议定价区间 | 根据竞争价格带测算               |
| 竞争度评估   | 高/中/低 + 具体数值              |
| 预估利润空间 | 按建议售价 - 估算成本            |
| 核心卖点方向 | 3-5个核心卖点                    |
| 差异化机会   | 和现有热销商品的差异点           |
