## 执行摘要

美潮电商是一个跨境电商数据采集与智能分析系统，支持淘宝、Amazon 等多平台的商品数据获取、搜索和验证。系统采用六边形架构（领域驱动设计），核心特点包括：

- **多平台支持**：淘宝（已实现）、Amazon（Mock → 待实现）、可扩展
- **完整容错系统**：错误分类、熔断器、降级执行、冷却管理、决策日志
- **数据管道**：ETL 过滤器链（Fetch → Validate → Dedupe → Store → Cache）
- **智能缓存**：Redis 缓存层，O(1) 键管理
- **开放搜索降级**：Bing/Tavily 作为最终降级方案

**使用示例**:

```typescript
// 继承 BasePlatformAdapter 即可获得所有容错能力
class TaobaoAdapter extends BasePlatformAdapter {
  async fetchProduct(platformId: string, options?: FetchOptions) {
    // 自动降级、重试、熔断、冷却
    const result = await this.fetchWithFailover(
      async (source) => this.doFetchProduct(platformId, source.id, options),
      { preferredSource: options?.preferredSource, maxSources: 2 },
    );
    return result;
  }

  // 只需实现核心业务逻辑
  private async doFetchProduct(platformId: string, sourceId: string) {
    return await this.productApi.getProduct(platformId);
  }
}
```

## 业务功能

### 1. 产品数据采集

**功能描述**: 从多个电商平台采集产品数据，支持自动降级和容错。

**支持的采集方式**:

1. **官方 API** (优先级 1)
   - 免费或低成本
   - 最可靠
   - 数据最准确

2. **第三方 API** (优先级 2)
   - 付费服务
   - 速度快
   - 数据质量参差不齐

3. **技能爬虫** (优先级 3)
   - 付费服务
   - 速度慢
   - 数据可能不完整

4. **开放搜索** (优先级 4)
   - 免费或低成本
   - 数据不准确
   - 最终降级方案

**采集流程**:

```
输入：platform + platformIds
  ↓
尝试官方 API
  ├─ 成功 → 返回结果
  └─ 失败 → 尝试第三方 API
      ├─ 成功 → 返回结果
      └─ 失败 → 尝试爬虫
          ├─ 成功 → 返回结果
          └─ 失败 → 尝试开放搜索
              ├─ 成功 → 返回结果
              └─ 失败 → 返回错误
```

### 2. 产品搜索

**功能描述**: 通过关键词搜索产品，支持多个搜索 Provider。

**支持的搜索 Provider**:

1. **Bing Shopping API**
   - 免费层：1000 次/月
   - 支持自定义搜索配置
   - 购物结果优化

2. **Tavily API**
   - 通过 OpenClaw tavily 插件
   - 需要配置 API Key

**搜索流程**:

```
输入：keyword + options
  ↓
尝试主 Provider
  ├─ 成功 → 返回结果
  └─ 失败 → 尝试 fallback Provider
      ├─ 成功 → 返回结果
      └─ 失败 → 返回错误
```

### 3. 平台验证

**功能描述**: 验证平台 API 配置是否正确，生成验证报告。

**验证项**:

- API 连接性
- 认证配置
- 数据完整性
- 响应时间
- 成功率

**输出**:

- 验证报告（JSON）
- 统计数据
- 降级趋势分析

### 4. 配额管理

**功能描述**: 跟踪 API 调用配额，防止超额使用。

**功能**:

- 实时配额跟踪
- 预算告警
- 配额使用统计
- 冷却机制

### 5. 告警服务

**功能描述**: 当系统出现异常时，发送告警通知。

**支持的通知渠道**:

- 飞书（Feishu）
- Email
- Webhook

**告警场景**:

- API 配额超额
- 数据源不健康
- 降级频繁发生
- 错误率过高

## 总结

美潮电商系统是一个完整的跨境电商数据采集与分析平台，核心优势在于：

1. **完整的容错系统** - 错误分类、熔断器、降级执行、冷却管理、决策日志
2. **六边形架构** - 领域核心无外部依赖，易于测试和扩展
3. **数据管道** - ETL 过滤器链，易于扩展和定制
4. **多平台支持** - 淘宝已实现，Amazon 待实现，易于添加新平台
5. **可配置降级策略** - 4 种预置策略 + 自定义策略

系统的核心设计理念是**复用优于创造**，通过 BasePlatformAdapter 集成了完整的容错能力，新平台只需实现核心业务逻辑即可。
