# 微信插件支持特性与技术文档

## 概述

**插件名称：** `@tencent-weixin/openclaw-weixin`  
**当前版本：** 2.1.7  
**插件 ID：** `openclaw-weixin`  
**GitHub 仓库：** https://github.com/Tencent/openclaw-weixin  
**npm dist-tag：** `latest`（2.0.x）、`legacy`（1.0.x）

微信插件是 OpenClaw 的微信渠道插件，支持通过 QR 码扫码完成登录授权，实现个人微信号的消息收发能力。该插件使用 **iLink 协议** 与腾讯后端通信，提供完整的消息类型支持。

## 核心特性

### 1. 登录方式

- **QR 码扫码登录**：终端显示二维码，手机微信扫码确认授权
- **凭证自动保存**：登录成功后凭证自动保存到本地，无需重复登录
- **多账号支持**：支持多个微信号同时在线，每个账号独立管理

### 2. 消息类型支持

| 消息类型 | 类型代码  | 支持状态    | 说明                               |
| -------- | --------- | ----------- | ---------------------------------- |
| 文本消息 | `type: 1` | ✅ 完全支持 | 支持 Markdown 部分格式（流式过滤） |
| 图片消息 | `type: 2` | ✅ 完全支持 | CDN 传输 + AES-128-ECB 加密        |
| 语音消息 | `type: 3` | ✅ 完全支持 | SILK 编码格式                      |
| 文件消息 | `type: 4` | ✅ 完全支持 | CDN 传输 + AES-128-ECB 加密        |
| 视频消息 | `type: 5` | ✅ 完全支持 | CDN 传输 + AES-128-ECB 加密        |

### 3. 功能支持矩阵

| 功能         | 支持状态  | 说明                          |
| ------------ | --------- | ----------------------------- |
| 私聊消息     | ✅ 支持   | 完整的私聊消息收发            |
| 群聊消息     | ❌ 不支持 | 微信个人号无官方 Bot API      |
| 输入状态指示 | ✅ 支持   | 发送/取消"正在输入"状态       |
| 消息引用回复 | ✅ 支持   | `ref_msg` 字段支持引用消息    |
| 流式文本过滤 | ✅ 支持   | 2.1.3+ 支持 Markdown 部分格式 |
| 多账号管理   | ✅ 支持   | 支持多微信号同时在线          |

### 4. 限制说明

- **仅支持私聊**：微信个人号没有官方群聊 Bot API，插件仅支持私聊场景
- **个人账号模式**：使用真实微信个人号登录，非企业微信或公众号模式
- **iLink 协议依赖**：需与腾讯 iLink 后端通信，要求稳定的网络连接

## 安装与配置

### 前提条件

1. 已安装 OpenClaw（`openclaw` CLI 可用）
2. 检查版本：`openclaw --version`

### 一键安装

```bash
npx -y @tencent-weixin/openclaw-weixin-cli install
```

### 手动安装

#### 1. 安装插件

```bash
openclaw plugins install "@tencent-weixin/openclaw-weixin"
```

#### 2. 启用插件

```bash
openclaw config set plugins.entries.openclaw-weixin.enabled true
```

#### 3. 扫码登录

```bash
openclaw channels login --channel openclaw-weixin
```

终端会显示一个二维码，用手机微信扫码并在手机上确认授权。确认后，登录凭证会自动保存到本地。

#### 4. 重启网关

```bash
openclaw gateway restart
```

### 添加多个微信账号

```bash
openclaw channels login --channel openclaw-weixin
```

每次扫码登录都会创建一个新的账号条目，支持多个微信号同时在线。

### 多账号上下文隔离

当多个微信号同时登录时，建议配置会话隔离策略，避免上下文混淆：

```bash
openclaw config set session.dmScope per-account-channel-peer
```

此配置确保每个微信账号的私聊会话独立管理。

## 架构设计

### 认证模式

微信插件采用 **OpenClaw 端认证 + 平台端认证** 双重认证机制：

```
┌─────────────────────────────────────────────────────────┐
│                    微信插件认证流程                       │
└─────────────────────────────────────────────────────────┘
                          │
        ┌─────────────────┴─────────────────┐
        │                                     │
   ┌────▼────┐                         ┌─────▼─────┐
   │ OpenClaw │                         │ 微信平台   │
   │ 端认证  │                         │ 端认证    │
   └────┬────┘                         └─────┬─────┘
        │                                     │
        │ 1. 用户扫码授权                      │
        │ 2. iLink Token 获取                │
        │                                     │
        └──────────────┬──────────────────────┘
                       │
              ┌────────▼────────┐
              │ 双重认证完成     │
              │ 消息通道建立     │
              └─────────────────┘
```

#### 1. 平台端认证（微信）

- **认证方式**：QR 码扫码授权
- **认证凭证**：`Authorization: Bearer <token>`（登录后获取）
- **认证范围**：验证微信个人号身份，确保操作合法性
- **安全机制**：手机端确认授权，防止恶意登录

#### 2. OpenClaw 端认证

- **dmPolicy 配置**：控制私聊权限策略
  - `open`：允许所有私聊
  - `allowlist`：仅允许白名单用户
  - `pairing`：配对机制，需用户主动发起
  - `disabled`：禁用私聊

- **权限验证流程**：
  1. 检查消息发送者是否在白名单
  2. 验证 dmPolicy 策略配置
  3. 通过后才将消息投递给 Agent

## 后端 API 协议

微信插件通过 HTTP JSON API 与腾讯 iLink 后端通信。所有接口均为 `POST` 方法，请求和响应均为 JSON 格式。

### 通用请求头

| Header              | 值                 | 说明                       |
| ------------------- | ------------------ | -------------------------- |
| `Content-Type`      | `application/json` | JSON 数据格式              |
| `AuthorizationType` | `ilink_bot_token`  | 固定值，标识认证类型       |
| `Authorization`     | `Bearer <token>`   | 登录后获取的访问令牌       |
| `X-WECHAT-UIN`      | `<base64>`         | 随机 uint32 的 base64 编码 |

### 接口列表

| 接口           | 路径           | 说明              | 调用时机         |
| -------------- | -------------- | ----------------- | ---------------- |
| `getUpdates`   | `getupdates`   | 长轮询获取新消息  | 持续轮询         |
| `sendMessage`  | `sendmessage`  | 发送消息          | Agent 回复时     |
| `getUploadUrl` | `getuploadurl` | 获取 CDN 上传参数 | 发送媒体文件前   |
| `getConfig`    | `getconfig`    | 获取账号配置      | 发送输入状态前   |
| `sendTyping`   | `sendtyping`   | 发送/取消输入状态 | Agent 处理消息时 |

### getUpdates - 长轮询获取消息

获取新消息的核心接口，使用长轮询机制减少网络开销。

**请求体：**

```json
{
  "get_updates_buf": ""
}
```

| 字段              | 类型     | 说明                                       |
| ----------------- | -------- | ------------------------------------------ |
| `get_updates_buf` | `string` | 上次响应返回的同步游标；首次请求传空字符串 |

**响应体：**

```json
{
  "ret": 0,
  "msgs": [
    {
      "seq": 12345,
      "message_id": 67890,
      "from_user_id": "wxid_xxx",
      "to_user_id": "wxid_yyy",
      "create_time_ms": 1712345678901,
      "session_id": "session_abc",
      "message_type": 1,
      "message_state": 2,
      "item_list": [
        {
          "type": 1,
          "text_item": { "text": "你好" }
        }
      ],
      "context_token": "ctx_token_xyz"
    }
  ],
  "get_updates_buf": "<new_cursor>",
  "longpolling_timeout_ms": 35000
}
```

| 字段                     | 类型              | 说明                             |
| ------------------------ | ----------------- | -------------------------------- |
| `ret`                    | `number`          | 返回码，`0` = 成功               |
| `errcode`                | `number?`         | 错误码（如 `-14` = 会话超时）    |
| `errmsg`                 | `string?`         | 错误描述                         |
| `msgs`                   | `WeixinMessage[]` | 消息列表                         |
| `get_updates_buf`        | `string`          | 新的同步游标，下次请求时回传     |
| `longpolling_timeout_ms` | `number?`         | 服务端建议的下次长轮询超时（ms） |

### sendMessage - 发送消息

向指定用户发送消息。

**请求体：**

```json
{
  "msg": {
    "to_user_id": "wxid_xxx",
    "context_token": "ctx_token_from_received_msg",
    "item_list": [
      {
        "type": 1,
        "text_item": { "text": "你好，这是回复消息" }
      }
    ]
  }
}
```

| 字段            | 类型            | 必填 | 说明                               |
| --------------- | --------------- | ---- | ---------------------------------- |
| `to_user_id`    | `string`        | ✅   | 目标用户 ID                        |
| `context_token` | `string`        | ❌   | 会话上下文令牌，从收到的消息中获取 |
| `item_list`     | `MessageItem[]` | ✅   | 消息内容列表                       |

**MessageItem 结构：**

```typescript
interface MessageItem {
  type: 1 | 2 | 3 | 4 | 5; // 1=TEXT, 2=IMAGE, 3=VOICE, 4=FILE, 5=VIDEO
  text_item?: { text: string };
  image_item?: ImageItem;
  voice_item?: VoiceItem;
  file_item?: FileItem;
  video_item?: VideoItem;
  ref_msg?: RefMessage; // 引用消息
}
```

### getUploadUrl - 获取 CDN 上传参数

发送媒体文件（图片/视频/文件）前，需先调用此接口获取 CDN 上传参数。

**请求体：**

```json
{
  "filekey": "file_identifier",
  "media_type": 1,
  "to_user_id": "wxid_xxx",
  "rawsize": 12345,
  "rawfilemd5": "abc123def456",
  "filesize": 12352,
  "thumb_rawsize": 1024,
  "thumb_rawfilemd5": "thumb_md5",
  "thumb_filesize": 1040
}
```

| 字段               | 类型      | 必填 | 说明                                 |
| ------------------ | --------- | ---- | ------------------------------------ |
| `filekey`          | `string`  | ✅   | 文件标识符                           |
| `media_type`       | `number`  | ✅   | `1` = IMAGE, `2` = VIDEO, `3` = FILE |
| `to_user_id`       | `string`  | ✅   | 目标用户 ID                          |
| `rawsize`          | `number`  | ✅   | 原文件明文大小（字节）               |
| `rawfilemd5`       | `string`  | ✅   | 原文件明文 MD5                       |
| `filesize`         | `number`  | ✅   | AES-128-ECB 加密后的密文大小         |
| `thumb_rawsize`    | `number?` | ⚠️   | 缩略图明文大小（IMAGE/VIDEO 时必填） |
| `thumb_rawfilemd5` | `string?` | ⚠️   | 缩略图明文 MD5（IMAGE/VIDEO 时必填） |
| `thumb_filesize`   | `number?` | ⚠️   | 缩略图密文大小（IMAGE/VIDEO 时必填） |

**响应体：**

```json
{
  "upload_param": "<base64_encrypted_params>",
  "thumb_upload_param": "<base64_encrypted_params>"
}
```


**响应体：**


| -------- | -------- | ------------------------------ |
| `status` | `number` | `1` = 正在输入，`2` = 取消输入 |

## CDN 媒体传输

所有媒体类型（图片/语音/文件/视频）通过 CDN 传输，使用 **AES-128-ECB** 加密。

### CDN 媒体引用结构 (CDNMedia)

```typescript
interface CDNMedia {
  encrypt_query_param?: string; // CDN 下载/上传的加密参数
  aes_key?: string; // base64 编码的 AES-128 密钥
}
```

### CDN 上传流程

```
┌──────────────────────────────────────────────────────────┐
│                    CDN 上传流程                          │
└──────────────────────────────────────────────────────────┘

1. 计算文件参数
   ┌──────────────┐
   │ 原始文件      │
   │ - rawsize    │
   │ - rawfilemd5 │
   │ - filesize   │ (AES-128-ECB 加密后大小)
   └──────┬───────┘
          │
          ▼
   ┌──────────────┐
   │ 缩略图(可选)  │
   │ - thumb_*    │
   └──────┬───────┘
          │
          ▼

2. 获取上传参数
   ┌──────────────┐
   │ getUploadUrl │
   │ API 调用     │
   └──────┬───────┘
          │
          ▼
   ┌──────────────────────┐
   │ upload_param         │
   │ thumb_upload_param   │
   └──────┬───────────────┘
          │
          ▼

3. 加密并上传
   ┌──────────────────────┐
   │ AES-128-ECB 加密      │
   │ ↓                    │
   │ PUT 上传到 CDN URL   │
   └──────┬───────────────┘
          │
          ▼

4. 构造消息引用
   ┌──────────────────────┐
   │ CDNMedia 引用        │
   │ - encrypt_query_param│
   │ - aes_key            │
   └──────┬───────────────┘
          │
          ▼

5. 发送消息
   ┌──────────────────────┐
   │ sendMessage API      │
   └──────────────────────┘
```

### CDN 下载流程

```
┌──────────────────────────────────────────────────────────┐
│                    CDN 下载流程                          │
└──────────────────────────────────────────────────────────┘

收到消息 → 提取 CDNMedia
          │
          ▼
使用 encrypt_query_param 构造 CDN URL
          │
          ▼
GET 下载加密数据
          │
          ▼
使用 aes_key 解密 (AES-128-ECB)
          │
          ▼
得到原始媒体文件
```

## 消息结构详解

### WeixinMessage 完整结构

```typescript
interface WeixinMessage {
  seq?: number; // 消息序列号
  message_id?: number; // 消息唯一 ID
  from_user_id?: string; // 发送者 ID (如 wxid_xxx)
  to_user_id?: string; // 接收者 ID
  create_time_ms?: number; // 创建时间戳（毫秒）
  session_id?: string; // 会话 ID
  message_type?: 1 | 2; // 1=USER, 2=BOT
  message_state?: 0 | 1 | 2; // 0=NEW, 1=GENERATING, 2=FINISH
  item_list?: MessageItem[]; // 消息内容列表
  context_token?: string; // 会话上下文令牌（回复时需回传）
}
```

### MessageItem 类型详解

#### 1. 文本消息 (type=1)

```json
{
  "type": 1,
  "text_item": {
    "text": "这是一条文本消息"
  }
}
```

**Markdown 支持（v2.1.3+）：**

从 2.1.3 版本开始，外发文本使用 `StreamingMarkdownFilter` 流式过滤，对 Markdown 从完全不支持变为部分支持：

- ✅ 支持：`**粗体**`、`*斜体*`、`` `代码` ``、`[链接](url)`
- ❌ 过滤：标题标记、列表标记、代码块标记等

#### 2. 图片消息 (type=2)

```json
{
  "type": 2,
  "image_item": {
    "cdn_media": {
      "encrypt_query_param": "...",
      "aes_key": "base64_encoded_key"
    },
    "width": 1920,
    "height": 1080
  }
}
```

#### 3. 语音消息 (type=3)

```json
{
  "type": 3,
  "voice_item": {
    "cdn_media": {
      "encrypt_query_param": "...",
      "aes_key": "base64_encoded_key"
    },
    "duration_ms": 5000,
    "format": "silk" // SILK 编码格式
  }
}
```

#### 4. 文件消息 (type=4)

```json
{
  "type": 4,
  "file_item": {
    "cdn_media": {
      "encrypt_query_param": "...",
      "aes_key": "base64_encoded_key"
    },
    "filename": "document.pdf",
    "size": 123456
  }
}
```

#### 5. 视频消息 (type=5)

```json
{
  "type": 5,
  "video_item": {
    "cdn_media": {
      "encrypt_query_param": "...",
      "aes_key": "base64_encoded_key"
    },
    "thumb_cdn_media": {
      "encrypt_query_param": "...",
      "aes_key": "base64_encoded_key"
    },
    "duration_ms": 30000,
    "width": 1920,
    "height": 1080
  }
}
```

#### 6. 引用消息 (ref_msg)

```json
{
  "type": 1,
  "text_item": { "text": "回复内容" },
  "ref_msg": {
    "message_id": 12345,
    "from_user_id": "wxid_xxx",
    "create_time_ms": 1712345678901,
    "text_preview": "引用的原消息..."
  }
}
```

## 配置文件示例

### 完整配置示例

```json
{
  "plugins": {
    "entries": {
      "openclaw-weixin": {
        "enabled": true,
        "config": {}
      }
    }
  },
  "channels": {
    "openclaw-weixin": {
      "accounts": {
        "wxid_xxx": {
          "name": "我的微信号",
          "enabled": true
        }
      }
    }
  },
  "session": {
    "dmScope": "per-account-channel-peer"
  }
}
```

### dmPolicy 配置

```bash
# 允许所有私聊
openclaw config set dmPolicy open

# 仅允许白名单用户
openclaw config set dmPolicy allowlist
openclaw config set allowlist '["wxid_xxx", "wxid_yyy"]'

# 配对机制（需用户主动发起）
openclaw config set dmPolicy pairing

# 禁用私聊
openclaw config set dmPolicy disabled
```

### 多账号配置

```bash
# 添加第一个账号
openclaw channels login --channel openclaw-weixin

# 添加第二个账号
openclaw channels login --channel openclaw-weixin

# 查看所有账号
```

## 故障排查

### 1. "requires OpenClaw >=2026.3.22" 错误

**原因**：OpenClaw 版本太旧，不兼容当前插件版本。

**解决方法**：

```bash
# 检查版本
openclaw --version

# 安装旧版插件线
openclaw plugins install @tencent-weixin/openclaw-weixin@legacy
```

### 2. Channel 显示 "OK" 但未连接

**原因**：插件未启用。

**解决方法**：

```bash
# 启用插件
openclaw config set plugins.entries.openclaw-weixin.enabled true

# 重启网关
openclaw gateway restart
```

### 3. 扫码登录超时

**原因**：网络不稳定或服务端响应慢。

**解决方法**：

- 2.1.4+ 版本已移除客户端超时限制，受服务端和网络栈限制
- 检查网络连接
- 尝试重新扫码登录

### 4. 消息发送失败

**可能原因**：

1. **会话超时**（errcode: -14）
   - 重新扫码登录获取新 token

2. **媒体文件上传失败**
   - 检查文件大小
   - 验证 AES-128-ECB 加密正确性
   - 确认 CDN 上传参数有效

3. **context_token 失效**
   - 从最新收到的消息中获取新的 context_token

### 5. 多账号会话混淆

**原因**：未配置会话隔离。

**解决方法**：

```bash
openclaw config set session.dmScope per-account-channel-peer
openclaw gateway restart
```

## 总结

微信插件 `@tencent-weixin/openclaw-weixin` 是 OpenClaw 生态中重要的个人账号模式插件，提供了完整的私聊消息处理能力。相比 Bot 模式平台，微信插件虽然不支持群聊，但在个人助理、客服等场景下具有独特优势。

**核心优势**：

- ✅ 完整的私聊消息支持（文本、图片、视频、文件、语音）
- ✅ 多账号并行支持
- ✅ QR 码便捷登录
- ✅ 流式 Markdown 过滤（v2.1.3+）
- ✅ 输入状态指示
- ✅ iLink 协议稳定通信

**使用限制**：

- ❌ 不支持群聊
- ❌ 依赖 iLink 后端网络连接
- ❌ 需要手机扫码授权（无法全自动）

**适用场景**：

- 个人 AI 助理
- 客服对话系统
- 微信生态集成（需私聊场景）
- 多平台统一接入（配合其他渠道插件）
