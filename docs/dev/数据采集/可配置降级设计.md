# 数据采集可配置降级设计

## 1. 概述

### 1.1 设计目标

参考 openclaw 的模型降级配置设计 (`AgentModelConfig`)，为数据采集模块实现可配置的降级机制，支持：

- **官方 API** (`official_api`) - 首选，通常免费或低成本
- **第三方 API** (`third_party_api`) - 备选，按次计费
- **爬虫** (`skill_crawler`) - 最后兜底，成本较高但无配额限制

### 1.2 参考：OpenClaw 模型降级配置

```typescript
// src/config/types.agents-shared.ts
export type AgentModelConfig =
  | string
  | {
      primary?: string;
      fallbacks?: string[];

  model: {
    primary: "anthropic/claude-opus-4-6",
    fallbacks: ["openai/gpt-4.1", "google/gemini-2.5-pro"]
  }
}
```

## 2. 配置结构设计

### 2.1 数据源标识格式

参考模型标识 `provider/model`，设计数据源标识格式：

```
{platform}/{sourceType}    // 类型标识
{platform}/{sourceId}      // 具体源标识
```

示例：
```
taobao/official_api        // 淘宝官方 API
taobao/third_party_api     // 淘宝第三方 API
taobao/skill_crawler       // 淘宝爬虫
amazon/sp_api              // Amazon SP-API (具体源)
amazon/product_api         // Amazon Product API (具体源)
```

### 2.2 类型定义

```typescript
// 单平台数据源配置（参考 AgentModelConfig）
export type PlatformDataSourceConfig =
  | string
  | {
      primary?: string;
      fallbacks?: string[];
    };

// 全局数据采集配置
export interface DataCollectionConfig {
  // 默认数据源策略
  default?: PlatformDataSourceConfig;
  
  // 按平台配置
  platforms?: Partial<Record<Platform, PlatformDataSourceConfig>>;
  
  // 全局设置
  settings?: DataCollectionSettings;
}

// 全局设置
export interface DataCollectionSettings {
  // 最大尝试数据源数量
  maxFallbackSources?: number;
  // 启用过期缓存降级
  enableStaleCache?: boolean;
  // 过期缓存最大年龄（毫秒）
  staleCacheMaxAge?: number;
  // 熔断器配置
  circuitBreaker?: CircuitBreakerSettings;
}

// 熔断器配置
export interface CircuitBreakerSettings {
  enabled?: boolean;
  failureThreshold?: number;
  openDuration?: number;
}
```

## 3. 解析函数设计

参考 `src/config/model-input.ts`：

```typescript
// 解析主数据源
export function resolvePrimaryDataSource(
  config?: PlatformDataSourceConfig
): string | undefined {
  if (typeof config === "string") {
    return config.trim() || undefined;
  }
  if (!config || typeof config !== "object") {
    return undefined;
  }
  return config.primary?.trim() || undefined;
}

// 解析 fallback 列表
export function resolveFallbackDataSources(
  config?: PlatformDataSourceConfig
): string[] {
  if (!config || typeof config !== "object") {
    return [];
  }
  return Array.isArray(config.fallbacks) ? config.fallbacks : [];
}

// 构建候选数据源列表
export function buildDataSourceCandidates(
  config?: PlatformDataSourceConfig,
  defaultConfig?: PlatformDataSourceConfig
): string[] {
  const primary = resolvePrimaryDataSource(config) 
    || resolvePrimaryDataSource(defaultConfig);
  
  const fallbacks = [
    ...resolveFallbackDataSources(config),
    ...resolveFallbackDataSources(defaultConfig)
  ];
  
  // 去重
  const candidates = new Set<string>();
  if (primary) candidates.add(primary);
  fallbacks.forEach(f => candidates.add(f));
  
  return Array.from(candidates);
}
```

## 4. 与现有实现的兼容性

### 4.1 DataSource 值对象扩展

```typescript
// 现有 DataSource 字段
interface DataSourceData {
  id: string;
  platform: Platform;
  type: DataSourceType;
  priority: number;      // ← 将由配置决定
  costPerCall: number;
  dailyQuota: number;
  usedQuota: number;
  isAvailable: boolean;
  lastError?: string;
  lastSuccessAt?: Date;
}

// 新增：从配置计算优先级
function computePriorityFromConfig(
  sourceId: string,
  candidates: string[]
): number {
  const index = candidates.indexOf(sourceId);
  return index >= 0 ? index + 1 : 999;
}
```

### 4.2 BasePlatformAdapter 集成

```typescript
class BasePlatformAdapter {
  // 新增：配置解析
  protected resolveDataSourceCandidates(
    platform: Platform,
    options?: FetchOptions
  ): DataSource[] {
    const configCandidates = buildDataSourceCandidates(
      this.platformConfig?.[platform],
      this.defaultConfig
    );
    
    const preferredOverride = options?.preferredSource;
    if (preferredOverride && !configCandidates.includes(preferredOverride)) {
      configCandidates.unshift(preferredOverride);
    }
    
    // 过滤可用数据源
    return configCandidates
      .map(id => this.dataSources.get(id))
      .filter((ds): ds is DataSource => 
        ds != null && ds.isAvailable && ds.hasRemainingQuota()
      );
  }
}
```

## 6. CLI 命令设计

参考 `openclaw models fallbacks` 命令：

```bash
# 查看当前配置
openclaw meichao sources list

# 查看指定平台配置
openclaw meichao sources list --platform taobao

# 设置主数据源
openclaw meichao sources set-primary taobao official_api

# 添加 fallback
openclaw meichao sources add-fallback taobao third_party_api

# 移除 fallback
openclaw meichao sources remove-fallback taobao third_party_api

# 重置为默认配置
openclaw meichao sources reset taobao
```
