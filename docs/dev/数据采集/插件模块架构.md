# OpenClaw 插件模块架构

## 概述

OpenClaw 采用模块化插件架构，支持多种类型的插件扩展：
- **Channel Plugins**: 消息通道插件 (Discord, Telegram, WhatsApp 等)
- **Provider Plugins**: AI 模型提供商插件 (Anthropic, OpenAI, Google 等)
- **Tool Plugins**: Agent 工具插件
- **Memory Plugins**: 记忆/向量存储插件
- **Speech Plugins**: 语音合成/识别插件
- **Web Search Plugins**: 网络搜索插件
- **Media Understanding Plugins**: 媒体理解插件
- **Image Generation Plugins**: 图像生成插件

│     └── 最高优先级，用户显式指定的路径                           │
│                                                                │
│  2. global     (~/.openclaw/extensions, explicit installs)     │
│     └── 显式安装的插件                                          │
│                                                                │
│  3. bundled    (extensions/* in repo)                          │
│     ├── 内置插件，保留 plugin id                                │
│     └── 除非用户配置 override                                   │
│                                                                │
│  4. workspace  (${workspaceDir}/.openclaw/extensions)          │
│     ├── 项目本地插件                                            │
│     └── 最低优先级                                              │
│                                                                │
└────────────────────────────────────────────────────────────────┘

Duplicate Resolution:
  - 同一个 plugin id 出现多次时，按 origin 优先级选择
  - 被覆盖的插件记录 status="disabled", error="overridden by X plugin"

import { definePluginEntry } from "openclaw/plugin-sdk/plugin-entry";

          defaultModel: "anthropic/claude-sonnet-4-6",
        }),
      ],

      resolveDynamicModel(ctx) {
        // 处理未知模型 ID 的前向兼容

      },
      
      // 能力声明
      capabilities: {
        providerFamily: "anthropic",
      },
      
      // 缓存支持
      isCacheTtlEligible: () => true,
    });
    
    // 注册媒体理解能力
    api.registerMediaUnderstandingProvider({

      // ...
    });
  },
});

## Tool Plugin 深入解析

Tool Plugin 是为 Agent 提供 Agent Tool 的插件类型。与 Channel Plugin 不同，Tool Plugin 不处理消息通道，而是提供可被 Agent 调用的工具函数。

### Tool Plugin 架构

### Tool 注册流程

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           Tool Registration Flow                                 │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│   1. Plugin Entry Point                                                         │
│   ┌──────────────────────────────────────────────────────────────────────────┐  │
│   │ // src/index.ts 或 src/tool.ts                                            │  │
│   │ export async function register(api: OpenClawPluginApi): Promise<void> { │  │
│   │   const tool = createMyTool(context);                                    │  │
│   │   api.registerTool(tool, { name: 'my-tool' });                           │  │
│   │ }                                                                        │  │
│   └──────────────────────────────────────────────────────────────────────────┘  │
│                                      │                                          │
│                                      ▼                                          │
│   2. API Registration                                                           │
│   ┌──────────────────────────────────────────────────────────────────────────┐  │
│   │ // src/plugins/registry.ts                                                │  │
│   │ registerTool(toolOrFactory, options): void {                              │  │
│   │   const entry = {                                                         │  │
│   │     pluginId: this.currentPluginId,                                       │  │
│   │     toolOrFactory,                                                        │  │
│   │     options: { name, names, optional }                                   │  │
│   │   };                                                                      │  │
│   │   this.registry.tools.push(entry);                                       │  │
│   │ }                                                                         │  │
│   └──────────────────────────────────────────────────────────────────────────┘  │
│                                      │                                          │
│                                      ▼                                          │
│   3. Tool Resolution (Runtime)                                                  │
│   ┌──────────────────────────────────────────────────────────────────────────┐  │
│   │ // src/plugins/tools.ts                                                   │  │
│   │ function resolvePluginTools(plugins, context): AnyAgentTool[] {          │  │
│   │   const tools: AnyAgentTool[] = [];                                       │  │
│   │   for (const entry of registry.tools) {                                   │  │
│   │     const result = entry.toolOrFactory(context);                        │  │
│   │     if (result === null && entry.options.optional) continue;            │  │
│   │     const toolsArray = Array.isArray(result) ? result : [result];       │  │
│   │     for (const tool of toolsArray) {                                      │  │
│   │       toolMeta.set(tool, { pluginId, optional });                        │  │
│   │       tools.push(tool);                                                   │  │
│   │     }                                                                     │  │
│   │   }                                                                       │  │
│   │   return tools;                                                           │  │
│   │ }                                                                         │  │
│   └──────────────────────────────────────────────────────────────────────────┘  │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 实现模式

#### 模式 1: 单一动作工具 (Single-Action Tool)

最简单的 Tool Plugin 实现，提供单一功能：

```typescript
// extensions/my-tool/src/tool.ts
import { Type } from "@sinclair/typebox";
import type { AnyAgentTool } from "../../src/agents/tools/common";
import type { OpenClawPluginToolContext } from "../../src/plugins/types";

export function createMyTool(context: OpenClawPluginToolContext): AnyAgentTool {
  const { config, deliveryContext, hooks } = context;
  
  return {
    name: "my-action",
    label: "My Action",
    description: "Perform a specific action",
    parameters: Type.Object({
      input: Type.String({ description: "Input to process" }),
      options: Type.Optional(Type.Object({
        verbose: Type.Optional(Type.Boolean())
      }))
    }),
    
    execute: async (toolCallId, params, signal, onUpdate) => {
      try {
        // 1. 执行核心逻辑
        const result = await doWork(params.input, params.options);
        
        // 2. 可选：发送进度更新
        onUpdate?.({ status: "completed", progress: 100 });
        
        // 3. 返回结果
        return { output: result };
      } catch (error) {
        return { 
          output: null, 
          error: error instanceof Error ? error.message : String(error) 
        };
      }
    }
  };
}

export async function register(api: OpenClawPluginApi): Promise<void> {
  api.registerTool(createMyTool, { name: "my-action" });
}
```

        Type.Literal("image"),
        Type.Literal("link"),
        Type.Literal("friends"),
        Type.Literal("groups"),
        Type.Literal("me"),
        Type.Literal("status")
      ], { description: "Action to perform" }),
      // 动作特定参数
      message: Type.Optional(Type.String()),

      // ...

### 最佳实践

1. **单一职责**: 每个 Tool 应该只做一件事
2. **清晰的 Schema**: 参数描述要完整，方便 LLM 理解
3. **错误处理**: 始终返回 `AgentToolResult`，即使出错
4. **进度反馈**: 长时间操作使用 `onUpdate` 报告进度
5. **Abort 支持**: 使用 `signal` 支持取消操作
6. **可选工具**: 条件性工具标记 `optional: true`
7. **动作模式**: 多个相关操作用 `action` 参数合并到一个 Tool

## 总结

OpenClaw 的插件系统是一个完整的模块化架构，具有以下特点：

1. **多类型支持**: 支持通道、提供商、工具、记忆、语音、媒体理解、图像生成、网络搜索等多种插件类型

2. **统一注册 API**: 通过 `OpenClawPluginApi` 提供一致的注册接口

3. **灵活的发现机制**: 支持 bundled、workspace、global、config 四种来源

4. **安全控制**: 通过 allow/deny 列表、prompt injection 保护、执行审批等机制确保安全

5. **钩子系统**: 提供 25+ 钩子点，允许插件介入各个生命周期阶段

6. **缓存优化**: 使用 Jiti 进行 TypeScript 运行时编译，并支持注册表缓存

7. **配置驱动**: 通过 `openclaw.plugin.json` 声明能力，支持静态分析
