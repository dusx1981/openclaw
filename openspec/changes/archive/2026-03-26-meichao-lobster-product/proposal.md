## Why

美潮龙虾作为跨境电商商家，面临两大核心痛点：**数据分散难以整合**和**爆款识别效率低下**。多平台数据（淘宝、抖音、拼多多、亚马逊、Shopee等）分散在各处，竞品监控依赖人工，数据更新滞后；同时选品决策缺乏数据支撑，爆款机会易被遗漏。基于OpenClaw平台构建自动化数据采集与智能分析系统，可降低70%人工成本，提升3倍决策效率。

## What Changes

- **新增统一数据采集框架**：API优先策略（官方API → 聚合API → Skill爬虫），支持淘宝、1688、Amazon、速卖通、抖音等平台
- **新增配额管理系统**：免费额度跟踪、智能调度、成本监控
- **新增平台适配器架构**：YAML配置驱动，新增平台无需修改代码
- **新增多层容错机制**：重试 → 降级 → 缓存兜底 → 人工介入，目标成功率99%+
- **新增数据清洗与存储模块**：多源数据归一化、去重、结构化存储
- **新增实时监控预警系统**：价格/销量/评价异常波动检测，支持飞书告警
- **新增趋势报告生成器**：自动生成日报/周报/月报，可视化图表展示
- **新增竞品数据库**：竞品档案管理，历史数据追溯
- **新增热榜数据采集器**：各平台热销榜、飙升榜实时抓取
- **新增爆款特征分析引擎**：卖点提取、流量来源分析、转化路径拆解
- **新增选品机会挖掘算法**：供需比分析、价格带分析、趋势预测
- **新增智能推荐引擎**：个性化选品推荐、风险预警

## Impact

### 数据采集策略：API优先（四大原则）

**原则 1：API 优先**
- 官方免费API → 第三方聚合API → Skill爬虫
- 合规性：100%（官方API）→ 95%（聚合API）→ 灰色（爬虫）
- 稳定性：99%+（官方API）→ 95%（聚合API）→ 80%（爬虫）

**原则 2：平台易扩展**
- 插件化平台适配器架构
- YAML配置驱动，新增平台无需修改代码
- 统一 PlatformAdapter 接口

**原则 3：成功率保证**
- 多层容错：重试 → 降级 → 缓存兜底 → 人工介入
- 健康检查与熔断机制
- 目标成功率：99%+

**原则 4：省钱**
- 优先使用免费额度
- 智能调度减少重复调用
- 分级更新频率（热门商品高频，冷门商品低频）
