# 模块化开发计划

> 本计划定义了按模块开发的具体步骤，确保每个模块可独立开发、测试和验收。
> 
> **核心原则**：每个模块完成后必须通过测试验收，才能继续下一模块。

### M1: 领域核心模块

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  M1: 领域核心模块 ⚠️ 阻塞点                                                 │

│                                                                             │
│  职责: 定义业务类型、端口接口、实体、值对象                                  │
│  依赖: 无                                                                   │
│  时间: 2 天                                                                 │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  输入:                                                                      │
│  • design.md D12 (数据模型设计)                                             │
│  • design.md D15 (架构设计模式)                                             │
│                                                                             │
│  输出:                                                                      │
│  src/domain/                                                                │
│  ├── types.ts               # Platform, ProductStatus, SalesPeriod 等      │
│  ├── entities/                                                              │
│  │   └── Product.ts         # Product 实体（含验证方法）                   │
│  ├── value-objects/                                                         │
│  │   ├── DataSource.ts      # 数据源值对象                                 │
│  │   └── Quota.ts           # 配额值对象                                   │
│  └── ports/                                                                 │
│      ├── ProductRepository.ts   # 存储端口接口                             │
│      ├── PlatformGateway.ts     # 平台网关端口接口                         │
│      └── CacheProvider.ts       # 缓存提供者端口接口                       │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  实现步骤:                                                                  │
│                                                                             │
│  Step 1: 创建 types.ts（核心类型定义）                                      │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ export type Platform = 'taobao' | 'amazon' | 'douyin' | ...;        │   │
│  │ export type ProductStatus = 'active' | 'inactive' | 'deleted';      │   │
│  │ export type SalesPeriod = 'day' | 'week' | 'month';                 │   │
│  │                                                                      │   │
│  │ export interface ProductData {                                       │   │
│  │   platform: Platform;                                                │   │
│  │   platformId: string;                                                │   │
│  │   title: string;                                                     │   │
│  │   price: number;                                                     │   │
│  │   // ...                                                             │   │
│  │ }                                                                    │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Step 2: 创建 Product 实体（含验证）                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐   │
│  │ export class Product {                                               │   │
│  │   private constructor(private data: ProductData) {}                  │   │
│  │                                                                      │   │
│  │   static create(data: ProductData): Result<Product, ValidationError>│   │
│  │   updatePrice(price: number): Result<Product, ValidationError>       │   │
│  │   markAsTrending(): Product                                          │   │
│  │ }                                                                    │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  Step 3: 创建值对象 (DataSource, Quota)                                     │
│  Step 4: 创建端口接口 (Repository, Gateway, Provider)                      │
│  Step 5: 编写单元测试                                                       │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  验收标准:                                                                  │
│  □ 所有类型定义无外部依赖（除 TypeScript 标准库）                           │
│  □ 端口接口只有方法签名，无实现代码                                         │
│  □ Product 实体包含 create/updatePrice/markAsTrending 方法                 │
│  □ 值对象不可变，包含验证逻辑                                               │
│  □ 单元测试覆盖率 ≥ 90%                                                    │
│  □ 测试执行时间 < 1 秒                                                      │
│                                                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  测试命令:                                                                  │
│  $ pnpm test -- src/domain/__tests__/                                       │
│  $ pnpm test:coverage -- src/domain/__tests__/                              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
